# 世界観・用語・時系列

## 舞台と暮らし

和風ファンタジー世界の小さな港町「潮待ち」。入江を挟んで、瓦屋根の家並みと岬の灯台が向き合う。板壁の記録小屋、潮の祠、干潮にだけ現れる石段がある。灯台は木造の灯楼を石垣に載せたもの。灯室には金属の反射鏡と歯車があり、油と灯種でともした火を一定の間隔で沖へ送る。

人々は小袖・羽織・袴を着て、帆船と櫓船で島々を往来する。荷車、和紙の帳面、筆、測り綱、磁針盤を使う。汽船、電気灯、近代的な制服は登場しない。物語の中心は人と人の仕事・約束であり、戦闘や血統による選別ではない。

## 不思議の固定ルール

- 海には「潮霧」が生まれる。船乗りが知っている岸の輪郭や音をずらし、慣れた船にも同じ場所を巡らせる。意志を持つ敵ではなく、この土地の自然現象。
- 帰り灯の灯種は、潮の祠で一年かけて育てる火種。一定の巡りでともすことで潮霧の中に港の方角を通す。船を勝手に動かしたり、暗礁を消したりする力はない。
- 灯種は守り手の息と手の熱で安定する。強い願いや特別な血筋が力になるわけではなく、交代手順を習った人なら扱える。乱れたら補助灯と港の合図で対応し、独断で回転を早めない。
- 干潮に現れる星形の「潮結び」は旧船着き場と陸への向きを示す刻印。溝の貝殻粉が水を含むと淡く光る。宝の封印や行方不明者からの手紙ではない。
- 潮の祠の名札は、帰港の知らせを誰へ届けるかという生者の伝言帳。名を呼ぶと結び糸が一瞬ぬくもるが、船の位置や生死を教える術ではない。帰港は現物と船役の報告で確かめる。
- 死者の送り火と、生者の船を迎える帰り灯は別の儀礼。今回、死者の帰還や人を供物にする設定はない。

## 用語

| 用語 | 意味 |
| --- | --- |
| 潮待ち | 入江の奥にある港町。主人公とミオの故郷。 |
| 帰り灯 | 夕暮れに灯台から沖へ送る、生きた船のための道標。 |
| 灯種 | 潮の祠から灯台へ渡す火種。火入れ前は蓋付きの灯種箱で運ぶ。 |
| 潮霧 | 見慣れた港の輪郭や音をずらす海霧。 |
| 潮図師 | 潮、地形、船の記録を照合して航路図を作る仕事。レンは見習い。 |
| 潮結び | 石段に彫られた星形の旧船着き場の印。短線は陸への向き。 |
| 名預かり | 祠で帰港の連絡先を預かり、帰った船と照合して知らせる役。 |
| 港の記録小屋 | 海図・入出港帳・祠から移された古帳面を保管。 |
| 鳴子綱 | 帰港時に港で鳴らす木の合図。船が着いたことは人が確認する。 |

## 一日の時系列

霧の出た干潮の朝から夕暮れまで。ミオと主人公が港で出会い、サヨが灯種を渡す。石段の調査経路は潮が戻る朝のうちに進む。岬を選んだ経路は道の整備・灯室の準備を手伝い、夕暮れを迎える。

レンは朝に記録小屋と石段で仕事をし、夕方に灯台へ観測記録を届けた後、主人公より短い裏道で港へ戻る。サヨは朝に港で灯種を渡し、石段の札を回収して祠と記録小屋を往復し、夕方は岸壁で名札の照合を行う。

石段の星の意味は調査経路で初めて知る。灯台・船迎え経路では、主人公がその知識を持つ前提で話さない。朝の結末では当日の帰港はまだ起こらず、夕方のための仕事を終える。
