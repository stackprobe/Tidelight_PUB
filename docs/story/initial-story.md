# 物語開始時点

## 時間・場所

潮霧の出ている干潮の朝。和風の港町「潮待ち」の、古い石段の上段。

## 主人公

名前・性別は固定せず、地の文は一人称を避ける。しばらく町を離れており、昨日戻ったばかり。ミオの幼なじみで、灯台の昔の音や匂いは覚えているが、灯守の手順や潮結びの意味は知らない。レンとは以前に顔を合わせた程度。サヨとは幼いころに会っているが、名預かりの仕事を見るのは初めて。

## 冒頭の状況

潮が引き、普段は水に沈む石段の下段が現れている。今夜、ミオは祖父の付き添いを離れて初めて主当番を務める。祖父は健在で町におり、必要なら交代できる。ミオは不安を隠し、主人公に岬の準備を手伝ってほしいと思っている。サヨが祠の灯種を運んでくる。

## 人物の開始状態

| ID | 居場所・目的・知識 |
| --- | --- |
| mio | 港で主人公を探している。灯種を受け取り、岬の掃除と灯室の準備へ向かう。潮結びが昔の船着き場の印であることは知るが、古帳面の連絡先の詳細は知らない。 |
| ren | 記録小屋で古い海図を整理中。朝は石段の付近を陸から測り、夕方に灯台へ記録を届け、その後は港で観測手帳を受け取る予定。主人公の発見をまだ知らない。 |
| sayo | 祠から灯種箱を持って港へ。灯種を渡した後、石段の目印の縄を確かめ、帰港を待つ家から預かった名札を整える。主人公がどの道を選ぶかは知らない。 |

## 経路への引き継ぎ

岬へは石段の調査後にも行ける。その合流先では調査結果の知識を要求しない。各経路の主人公が読んでいない帳面や聞いていない話を知っていることにしない。実際の登退場と台詞は実行データに記述する。
