# シナリオ執筆資料

『潮待ちの灯』のパート執筆・設定追加・設定修正の入口です。このディレクトリの Markdown を執筆用設定の正本とします。ゲームはこれらを読み込みません。公開時は従来どおり `DocRoot/` の中身だけを配置します。

## 参照順

1. [世界観・用語・時系列](world.md)
2. [物語開始時点](initial-story.md)
3. [登場人物一覧](#登場人物一覧)から、登場する人物の設定
4. [パート一覧と接続](parts.md)、執筆対象の接続元・接続先の実際のパートデータ

背景・立ち絵を追加・修正する際は [画像サイズ規格と制作記録](assets.md) も必ず確認してください。元画像を約90％に縮小して描画する方針で統一しています。

開始時点の状態は冒頭用です。途中のパートでは、接続元を通った結果の時間・場所・人物の知識や行動を確認してください。複数の経路から入れるパートは、どの経路でも成立するように執筆します。

## 追加・修正の方法

- 世界観や用語は `world.md`、冒頭の状況は `initial-story.md`、人物の固定設定は `characters/<ID>.md` に記述します。人物を追加したら上の一覧にも追加してください。
- 人物設定には ID・名前・役割・性格・生い立ち・口調（人称と台詞例）・行動規範・人間関係を記載します。未設定の項目や検討案はその旨を明記し、確定設定と区別してください。
- 人間関係は相手のキャラクター ID または「主人公」など対象が分かる名称で記載します。ID はゲーム側の定義と揃えてください。
- 設定を変更するときは既存の公開パートとの矛盾を確認し、影響する台詞や分岐も必要に応じて修正します。設定の変更だけではゲームの内容は変わりません。
- パートの追加・修正・公開状態の変更時は `parts.md` の要約と接続情報も更新し、実際の `DocRoot/data/manifest.js` および `parts/*.js` と一致させます。
- 名前・立ち絵・表情・背景など実行に必要な変更があれば、`DocRoot/data/` の表示データと画像も更新します。性格・世界観・開始状況などの執筆専用情報は Markdown に置き、ゲームデータへ重複して保存しません。

## 実装時の確認

パートの作成手順は [開発・運用ガイド](../development.md#シナリオの追加) を参照してください。公開済みパート ID とステップ ID はセーブ再開に使うため維持します。

`node tools/validate.mjs` でゲームデータの形式・参照・画像を検証します。Markdown の設定内容やパートとの意味的な整合性は自動検証されないため、執筆・設定変更時に確認してください。

パート末尾は二択の `choice`、または結末の `end` にします。`end` には `id`・`type: "end"`・結末名と短い説明の `text` を指定します。結末では自動保存して「タイトルへ」を表示し、再開するとその結末を表示します。結末へ進む直前までの台詞も、セーブ再開時に復元されます。
